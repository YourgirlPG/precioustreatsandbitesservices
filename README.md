# 🍰 Web Showcase & Order Portal

A mobile-responsive, modern landing page built using pure **HTML5** and **CSS3**. Designed with a clean structure to showcase products, highlight custom packages, and provide direct contact links for seamless ordering.

🌐 **Live Demo:** (https://precioustreatsandbitesservices.netlify.app/)

---

## 🚀 Key Features

- **📱 Responsive Layout:** Optimized across deskstop, tablet, and mobile screens.
- **🎨 Custom Styling:** Clean typography, consistent color palette, and polished visual UI.
- **📲 Direct WhatsApp Ordering:** Styled quick-action links connecting buyers directly to WhatsApp.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox / CSS Grid)
- **Deployment:** Netlify
